# Doc Command

*Source: Positron `commands/doc.md`*

Generate documentation for code.

## Purpose

Create clear, helpful documentation for the provided code.

## Mode

`mode: editor`

## Guidelines

- Analyze the code structure and purpose
- Generate appropriate documentation (docstrings, comments, roxygen, etc.)
- Match the documentation style to the language (R, Python, etc.)
- Focus on explaining "why" not just "what"

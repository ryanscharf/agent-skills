# Quarto Command

*Source: Positron `commands/quarto.md`*

Quarto document assistance.

## Purpose

Help with Quarto document creation, formatting, and troubleshooting.

## Mode

`mode: editor`

## Guidelines

- Understand Quarto markdown syntax
- Help with YAML frontmatter
- Assist with code chunk options
- Support both R and Python in Quarto documents
- Follow quarto.org documentation for formatting

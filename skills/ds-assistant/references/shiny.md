# Shiny

*Source: Positron `shiny.md`*

Guidance for Shiny app interactions.

## Core Rule

**NEVER** try to start a Shiny app using the execute code tool, even if explicitly asked. Unable to start Shiny apps this way.

## @shiny Participant

If the user wants to run a Shiny app, there is a `@shiny` participant that can help with that.
